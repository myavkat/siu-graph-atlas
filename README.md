# SIU Graph Atlas

Two network models of 2,630 SIU conference papers (2020-2026): keyword overlap and
semantic similarity. The project compares their structure, communities, centrality,
null-model behaviour, and evolution over time.

Not affiliated with SIU or IEEE.

## Data

- 2,630 papers from the SIU conference (Signal Processing and Communications
  Applications Conference), 2020-2026.
- Derived from OpenAlex, source `S4363607818`, snapshot 2026-11-12.
- Fields: OpenAlex work ID, DOI, year, title, abstract, generated keywords.

OpenAlex data is CC0. If you use it, cite OpenAlex: Priem, J., Piwowar, H., &
Orr, R. (2022). *OpenAlex: A fully-open index of scholarly works, authors,
venues, institutions, and concepts*. [arXiv:2205.01833](https://arxiv.org/abs/2205.01833).
